How LogAegis catches tampering

Each record’s tag is an HMAC-SHA-256 computed with a secret key over the record and the previous tag. Tamper with the log as an attacker would, then press Verify.

Attacker actions

Administrator

Log is untouched. Press Verify to check it, or tamper with it first.

Demo only: the secret key lives in this page so the browser can compute real HMAC-SHA-256 tags. In LogAegis the key stays in protected storage, and the checkpoint is saved by the server where the attacker can’t change it. Tags are shown shortened to 8 characters.
